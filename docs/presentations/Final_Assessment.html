Core Concept

The "Escape Room" Puzzle Box

Students will create a single-player experience centered on an interactive "puzzle box" or a self-contained diorama. The objective is to design and implement a sequence of actions that the player must perform to solve the puzzle, demonstrating a practical application of logic, state management, and interaction design.

5

Requirements

Core C# Logic

The project will feature a clear, logical sequence of events managed through C# scripting. This includes using conditional statements (if/else) and data storage (e.g., bool hasKey) to accurately track the puzzle's state. For instance, the player must acquire a specific key to unlock a corresponding door, which in turn reveals a necessary button.

Object-Oriented Principles

The code will be structured using clear Object-Oriented principles. An Interactable base class with subclasses for specific items like Key, Door, and Button is required to demonstrate inheritance and polymorphism. A central PuzzleManager class will be implemented to encapsulate and manage the core puzzle state and progression logic.

Unity Fundamentals

The project will utilize core Unity engine features, including GameObjects, Components, MonoBehaviour event functions (Awake, Start, Update), and physics components such as Colliders, Triggers, and Rigidbodies to facilitate user interaction.

Database Integration

An element of the puzzle's state must be saved to a database. When a player quits and returns, the puzzle box must reload its last saved state (e.g., a "partially solved" state).
