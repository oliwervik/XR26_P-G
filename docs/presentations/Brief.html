Learning Journey

1

Clean Code Organization Foundation

Learn SOLID principles, design patterns, and project organization. Clean up messy code to follow best practices and create organized XR applications.

2

External Data Integration

Connect applications to real-world data through APIs and implement persistent storage. Handle asynchronous operations and create error handling.

3

Multiplayer Development

Build real-time collaborative experiences using Unity Netcode. Create multiplayer scenes with player interaction and shared objects.

4

Project Delivery

Integrate all learned concepts into a networked application with persistent data.

8

Technical Skills Mastery

Code Organization

SOLID principles, design patterns (Singleton, events), clean code organization, modular systems

API Integration

REST APIs, HTTP GET requests, async/await, JSON, error handling

Simple Data Persistence

SQLite-net basics, simple CRUD operations, basic data modeling, simple game data storage (no authentication)

Basic Multiplayer Networking

Unity Netcode basics, simple NetworkBehaviour, basic RPCs, simple state synchronization
